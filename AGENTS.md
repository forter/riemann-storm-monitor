## Critical Patterns

1. **Monitored Components**: Use `MonitoredBolt` and `MonitoredSpout` classes to wrap Storm bolts and spouts for monitoring.

2. **Event Awareness**: Implement the `EventsAware` interface in your bolt/spout classes to enable event and function throughput measuring.

3. **Configuration**: Set latency map configuration when initializing the topology:
   ```java
   conf.put("topology.monitoring.latencies.map.maxSize", 500);
   conf.put("topology.monitoring.latencies.map.maxTimeSeconds", 120);
   conf.put("topology.monitoring.latencies.map.maxConcurrency", 4);
   ```

4. **Event Sending**: Use the `EventSender` interface to send custom events from your components.

## Common Pitfalls to Avoid

1. Forgetting to wrap bolts and spouts with `MonitoredBolt` and `MonitoredSpout`.
2. Not implementing `EventsAware` interface when custom event tracking is needed.
3. Overlooking the configuration of latency map parameters.
